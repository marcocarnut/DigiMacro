{Ctrl+Shift+Left}...combined, in any order
{pause 1.5}wait, in seconds, 0.1 to 25.5
{11} or {x11}press the previous keystroke 11 more times

A code is one to five dots and dashes: a press under a quarter of a second is a dot, longer is a dash, and 700 ms of silence ends it. Sixty-two codes exist, so a table that uses many of them is easier to guess — which is what the lockout, still to be built, is for.

Macros are packed end to end, so the only limit is 497 bytes in total: two bytes of overhead each, one byte per keystroke, two per pause or repeat.
